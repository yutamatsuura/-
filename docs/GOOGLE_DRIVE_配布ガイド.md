## 🚀 Google Drive配布の手順

### ステップ1: Google Driveにフォルダを作成

1. https://drive.google.com にアクセス
2. 左上の「新規」ボタンをクリック
3. 「フォルダ」を選択
4. フォルダ名を入力: `Kyosho Backup v0.1.2`
5. 「作成」をクリック

---

### ステップ2: ファイルをダウンロード

GitHub Releasesから必要なファイルをダウンロードします：

#### 方法A: GitHubからダウンロード（推奨）

```bash
# コマンドラインでダウンロード（すべてのファイル）
gh release download v0.1.2 --repo yutamatsuura/kyosho-backup
```

ダウンロード後、以下の場所に保存されます：
```
現在のディレクトリ/
├── Kyosho.Backup_0.1.2_x64_ja-JP.msi
├── Kyosho.Backup_0.1.2_x64-setup.exe
├── Kyosho.Backup_0.1.2_aarch64.dmg
├── Kyosho.Backup_0.1.2_x64.dmg
├── Kyosho.Backup_0.1.2_amd64.deb
├── Kyosho.Backup_0.1.2_amd64.AppImage
└── Kyosho.Backup-0.1.2-1.x86_64.rpm
```

#### 方法B: 手動ダウンロード

1. https://github.com/yutamatsuura/kyosho-backup/releases/tag/v0.1.2 にアクセス
2. 「Assets」セクションから必要なファイルをクリックしてダウンロード

---

### ステップ3: Google Driveにアップロード

1. 作成した「Kyosho Backup v0.1.2」フォルダを開く
2. ダウンロードしたファイルをドラッグ&ドロップでアップロード
   - Windows用: `.msi` と `.exe`
   - macOS用: 両方の `.dmg`
   - Linux用: `.deb`, `.AppImage`, `.rpm`

**アップロード時間の目安**:
- 合計ファイルサイズ: 約118MB
- アップロード時間: 1-3分（回線速度による）

---

### ステップ4: 共有設定（セキュア）

#### オプションA: 特定のユーザーのみ（推奨）

1. フォルダを右クリック → 「共有」を選択
2. 「ユーザーやグループを追加」欄に知り合いのメールアドレスを入力
3. 権限を「閲覧者」に設定
4. 「送信」をクリック

**メリット**:
- ✅ 最もセキュア（指定したメールアドレスのみアクセス可能）
- ✅ 通知メールが自動送信される
- ✅ アクセス履歴が確認できる

#### オプションB: リンクを知っている全員（簡易）

1. フォルダを右クリック → 「共有」を選択
2. 「一般的なアクセス」セクションで「制限付き」をクリック
3. 「リンクを知っている全員」を選択
4. 権限を「閲覧者」に設定
5. 「リンクをコピー」をクリック

**注意**:
- ⚠️ リンクを知っている人は誰でもアクセス可能
- ⚠️ リンクが第三者に渡る可能性あり

---

### ステップ5: 知り合いに通知

#### テンプレート（メール/LINE/チャット用）

```

こんにちは、

エックスサーバー専用のバックアップツール「Kyosho Backup」をGoogle Driveで共有しました。

   [Google Driveリンクをここに貼り付け]

2. あなたのOSに合ったファイルをダウンロード：
   - Windows: Kyosho.Backup_0.1.2_x64_ja-JP.msi
   - Mac (M1/M2/M3): Kyosho.Backup_0.1.2_aarch64.dmg
```

## 🔒 セキュリティ上の注意

### アクセス権限の管理

- **推奨**: 「特定のユーザーのみ」で共有
- **定期的に確認**: 配布終了後は共有を解除

### ダウンロード後の確認

知り合いに以下を確認してもらいましょう：

1. **ファイルサイズ確認**
   - Windows (.msi): 約4MB
   - macOS (.dmg): 約5-6MB
   - Linux (.deb): 約6MB

2. **SmartScreen警告（Windows）**
   - 初回インストール時に「Windows によって PC が保護されました」と表示される場合あり
   - 「詳細情報」→「実行」で進めてください
   - （コード署名証明書未取得のため発生）

3. **macOS Gatekeeper（Mac）**
   - 「"Kyosho Backup"は開発元を確認できないため開けません」と表示される場合
   - 右クリック → 「開く」で許可してください

## 📊 配布状況の確認

### アクセス履歴の確認

1. Google Driveでフォルダを右クリック
2. 「アクティビティ」を選択
3. 誰がいつダウンロードしたか確認可能

### 共有の解除

配布を終了する場合：

1. フォルダを右クリック → 「共有」
2. ユーザー名の横の「×」をクリック
3. 「削除」を確認

## 💡 ヒント

### 容量不足の場合

Google Driveの無料容量は15GBです。Kyosho Backupは約118MBなので問題ありませんが、容量が足りない場合：

1. 不要なファイルを削除
2. Google Oneに加入（100GB: 250円/月）
3. または必要なOS版のみをアップロード（例: Windows版のみ → 6MB）

### 複数バージョンの管理

将来的に新バージョンをリリースする場合：

```
Google Drive/
├── Kyosho Backup v0.1.2/  ← 現在のバージョン
│   ├── Kyosho.Backup_0.1.2_x64_ja-JP.msi
│   └── ...
└── Kyosho Backup v0.2.0/  ← 将来のバージョン
    ├── Kyosho.Backup_0.2.0_x64_ja-JP.msi
    └── ...
```

## 🆘 トラブルシューティング

### Q: ダウンロードが途中で止まる

**A**:
- ブラウザを変更してみる（Chrome, Firefox, Safari）
- Google Drive アプリを使用する
- モバイルデータ通信ではなくWi-Fi接続を使用

### Q: 「このファイルはウイルススキャンできません」と表示される

**A**:
- ファイルサイズが大きい場合（AppImageなど）に表示される通常のメッセージ
- 「ダウンロード」をクリックして続行してOK

### Q: 知り合いが「アクセス権限がない」と言われる

**A**:
1. 共有設定を再確認
2. 正しいメールアドレスで招待されているか確認
3. 知り合いがGoogleアカウントにログインしているか確認
