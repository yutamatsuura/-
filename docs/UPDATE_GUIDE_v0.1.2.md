# Kyosho Backup v0.1.2 アップデートガイド

---

## 📋 このアップデートについて

**バージョン**: v0.1.1 → v0.1.2
**種別**: バグ修正

### 修正内容

特定のサイトでバックアップが失敗する不具合を修正しました。

> **詳細**: フォルダ名に `?` などの特殊文字が含まれている場合（例: WordPressテーマのフォルダ名）、
> Windows でローカルフォルダの作成に失敗してバックアップが中断される問題があります。
> v0.1.2 ではこの文字を自動的に `_` に置き換えてバックアップを完了させるよう修正しました。

**設定は引き継がれます。** 再設定は不要です。

---

## 👤 ユーザー向け：アップデート手順

### Windows の場合

#### ステップ1：新しいインストーラーをダウンロード

Google Drive の共有フォルダから **`Kyosho.Backup_0.1.2_x64_ja-JP.msi`** をダウンロードしてください。

> ダウンロード後、ダウンロードフォルダに保存されます。

---

#### ステップ2：インストーラーを実行

ダウンロードした `.msi` ファイルをダブルクリックします。

**「Windows によって PC が保護されました」と表示された場合：**

1. 「詳細情報」をクリック
2. 「実行」をクリック

> これは署名証明書の費用が高額なため省略しているためで、ツール自体に問題はありません。

---

#### ステップ3：インストール完了

「次へ」→「インストール」の順にクリックして完了です。
以前のバージョンは自動的に上書きされます。

---

#### ステップ4：動作確認

1. Kyosho Backup を起動
2. 設定画面を開き、SSH 秘密鍵が引き継がれていることを確認
3. 「接続テスト」を実行して正常に接続できることを確認

---

### macOS の場合

#### ステップ1：新しいインストーラーをダウンロード

お使いの Mac に合ったファイルをダウンロードしてください：

- **M1/M2/M3 Mac（Apple Silicon）**: `Kyosho.Backup_0.1.2_aarch64.dmg`
- **Intel Mac**: `Kyosho.Backup_0.1.2_x64.dmg`

> お使いの Mac が分からない場合：画面左上のリンゴマーク → 「この Mac について」→ チップ欄が「Apple M○」なら Apple Silicon です。

---

#### ステップ2：インストール

1. ダウンロードした `.dmg` ファイルをダブルクリック
2. 開いたウィンドウで `Kyosho Backup` を `Applications` フォルダにドラッグ
3. 「上書きしますか？」と聞かれたら「置き換える」を選択

**「開発元を確認できないため開けません」と表示された場合：**

1. Finder で「アプリケーション」フォルダを開く
2. `Kyosho Backup` を **右クリック** → 「開く」
3. 「開く」をクリック（初回のみ必要）

---

#### ステップ3：動作確認

アプリを起動して、設定が引き継がれていることを確認してください。

## 🔧 開発者向け：リリース手順チェックリスト

### 1. バージョン番号を更新する

**`src-tauri/Cargo.toml`**
```toml
version = "0.1.2"
```

**`src-tauri/tauri.conf.json`**
```json
"version": "0.1.2"
```

**`package.json`**
```json
"version": "0.1.2"
```

---

### 2. コミット＆タグをプッシュ

```bash
git add src-tauri/Cargo.toml src-tauri/tauri.conf.json package.json
git commit -m "release: v0.1.2 - Windowsパス禁止文字のサニタイズ修正"
git tag v0.1.2
git push origin main --tags
```

→ GitHub Actions が自動でビルド開始（約15分）

---

### 3. GitHub Releases からダウンロード

ビルド完了後、以下のコマンドで全ファイルをダウンロード：

```bash
gh release download v0.1.2 --repo yutamatsuura/kyosho-backup
```

---

### 4. Google Drive を更新

1. Google Drive に `Kyosho Backup v0.1.2` フォルダを新規作成
2. ダウンロードしたファイルをアップロード：
   - `Kyosho.Backup_0.1.2_x64_ja-JP.msi`（Windows 推奨）
   - `Kyosho.Backup_0.1.2_x64-setup.exe`（Windows 代替）
   - `Kyosho.Backup_0.1.2_aarch64.dmg`（Mac Apple Silicon）
   - `Kyosho.Backup_0.1.2_x64.dmg`（Mac Intel）
   - `Kyosho.Backup_0.1.2_amd64.deb`（Linux Ubuntu）
3. v0.1.1 フォルダと同じ共有設定をコピー
